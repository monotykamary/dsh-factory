# dsh-factory-domain

The authoritative Factory state machine and Typert Remote service.

Every browser/model mutation executes against SQLite and returns a complete revisioned snapshot. The service resolves project paths through the Worktree capability, validates task/flow ownership, groups explicit task graphs, derives ordinary and Scheduled flow status, activates due one-shot/recurring automation, stores all-terminal-run Triage review state, bounds task and comment attachments/activity, and reports stale revisions. Artifact review resolves the selected run's exact checkout, recursively lists bounded image/video files under `.artifacts`, rejects symlink/path escapes, and serves only the branded file revision returned by the preceding metadata list. Recognized files are AVIF, GIF, JPEG, PNG, WebP, M4V, MOV, MP4, OGV, and WebM. `artifactMediaLimit`, `artifactMediaBytes`, `artifactMediaTotalBytes`, and `artifactMediaDepth` configure listing count, per-file bytes, aggregate bytes, and nested-directory depth.

Each project stores task model, title model, optional title/description instructions, title opt-out, checkout lane/base ref, and setup command. Task creation first commits a deterministic prompt fallback plus the exact metadata request receipt, then uses the shared LLM service and conditionally settles generated title/description without overwriting concurrent edits. New Session Run later and Flow intake validate that the source Session is blank, create one draft per branded `intakeId`, retain `intakeSessionId` as provenance, start no run, and settle generated task and new-flow labels asynchronously before later queueing. A transport retry reuses its intake identity; a later submission from the same blank Session appends independent work. Empty prompt overrides reset to exported defaults.

Scheduler attempts and observed Session bindings carry distinct durable origins; takeover recovery never queues an observed binding when its host process or Session is temporarily absent. A local observed binding becomes running with its Agent. Its completion Consumer resolves only this process's active binding after fresh presence publication; a Session that disappears before `factory_finish` still fails abruptly, while a terminal report removes ownership before later conversation. Blank Sessions are never auto-adopted. Emerging observations become ordinary waiting tasks in one durable inbox flow per project. A live inbox task accepts graph-only dependency edits while execution fields remain protected. Dependency connection and replacement reject already succeeded, failed, or cancelled prerequisites; existing edges may naturally become terminal after execution. Relationship-complete inbox tasks or same-workspace standalone tasks can form one named standard flow.

Flow start queues ordinary draft nodes and enables timed nodes. Recurring tasks remain Scheduled between runs, advance their local-time cadence before dispatch, copy terminal receipts to immutable run history, and survive individual execution or process-loss failures. `reviewRuns()` marks selected regular, observed, or recurring terminal occurrences read under optimistic concurrency.
